1. Product Overview

🎯 Mission Statement

Finerminds is the exclusive social network for conscious builders - entrepreneurs, wellness practitioners, and personal growth enthusiasts who want to build meaningful businesses while developing themselves.

Core Value Proposition

  • Quality over Quantity: Curated community through Mindvalley qualification + peer approval
  • Growth-Focused: AI-powered matching for professional and personal development
  • Multi-Dimensional: Business + Wellness + Consciousness integration
  • People-First Architecture: Users span across all networks/groups/discussions

Target Audience: "Healthy Builders"

Primary Persona

  • Wellness-oriented entrepreneurs
  • Conscious business builders
  • Personal growth enthusiasts
  • Mindvalley community members

Qualification Criteria

  • 1+ year Mindvalley membership
  • 5+ programs completed
  • OR peer approval (3 endorsements, 0 rejections)
  • Aligned with conscious business values

2. Three-Level Architecture

Key Innovation: People exist at the universal layer and can participate across ALL networks, groups, and discussions simultaneously - creating unprecedented cross-pollination.
Level Description Activity Feed Chat Examples
Level 1: Networks Broad communities aligned with core interests ✅ Yes ✅ Multi-channel Wellness Founders Society, Mindvalley Membership
Level 2: Groups Focused communities within networks ✅ Yes ✅ Multi-channel AI Mastery, London Group, Female Founders
Level 3: Discussions Topic-specific chat threads ❌ No ✅ Single thread "Clawdbot Tips", "Brain Health Supplements"

Architecture Principles

  1. Cognitive Simplicity: Only 2 activity feeds (L1, L2) to reduce mental load
  2. Conversation Depth: Unlimited discussion creation at L3 for focused topics
  3. Democratic Creation: Anyone can create discussions and become admin
  4. Spam Protection: Invite limits and peer-based quality control

3. Feature Requirements

Level 1: Networks P1 - Launch Critical

Activity Feed App + Web

Network-wide posts, announcements, achievements, and member highlights

Network Chat App + Web

General network discussion, welcome channel, announcements channel

Member Directory App + Web

Curated member profiles with bio, expertise, and connection preferences

Events App + Web

Network events with RSVP, attendee visibility, and post-event networking

Web-Only Features (P2): "I'm Looking For" and "Peer Support" will launch web-only initially due to complexity, then migrate to app after validation.

Level 2: Groups P1 - Launch Critical

Group Activity Feed App + Web

Group-specific posts, discussions, resource shares, and member interactions

Group Chat Channels App + Web

Multiple themed channels per group (general, resources, events, random)

Resource Sharing App + Web

Link sharing, file uploads, resource libraries, and collaborative documents

Discussion Creation App + Web

One-click creation of Level 3 discussions from group context

Level 3: Discussions P1 - Launch Critical

Discussion Chat App + Web

Focused topic discussions with real-time messaging and thread management

Admin Controls App + Web

Creator becomes admin with invite control, member management, and moderation

Resource Integration App + Web

Share links, documents, and resources within discussion context

Invite Management App + Web

Configurable invite limits (default: 50) with spam prevention

4. User Flows

Primary Flow: Network → Group → Discussion

  1. Entry: User joins network (Mindvalley qualification or peer approval)
  2. Discovery: Browses network activity feed, discovers relevant groups
  3. Group Engagement: Joins group, participates in group chat and activity feed
  4. Discussion Creation: Starts focused discussion on specific topic
  5. Community Building: Invites relevant members, builds focused community
  6. Cross-Network Value: Discussion attracts members from multiple networks

Alternative Flows

Event-Driven Entry

External users join via event invitations, get limited access, then apply for full membership

Direct Network Invite

Existing members invite new users directly to networks with peer approval process

Cross-Network Discovery

Users discover discussions and groups across all their networks via unified activity feed

5. Technical Requirements

Chat Integration: GetStream

Decision: Use GetStream for chat functionality on both web and app platforms for reliable real-time messaging.

Chat Architecture

  • Network Chat: Multiple channels per network (general, announcements, welcome)
  • Group Chat: Multiple channels per group (general, resources, events, random)
  • Discussion Chat: Single thread per discussion with admin controls
  • Access Control: Membership-based access with role permissions

Database Schema (Key Entities)

Entity Key Relationships Critical Fields
Users Many-to-many with Networks, Groups, Discussions mindvalley_qualification, approval_status, bio, expertise
Networks One-to-many with Groups, Events qualification_criteria, admin_users, member_count
Groups Belongs to Network, has many Discussions parent_network, admin_users, chat_channels
Discussions Belongs to Group, has creator/admin creator_id, invite_limit, member_list, getstream_channel_id

API Requirements

  • User Management: Registration, qualification checking, peer approval workflow
  • Network Operations: Join requests, member management, activity feed generation
  • Group Operations: Group creation, membership, chat channel management
  • Discussion Operations: Creation, invitation, admin controls, GetStream integration
  • Cross-Platform Sync: Real-time sync between web and mobile apps

7. Success Metrics

Launch Metrics (Month 1)

Community Growth

  • 500+ qualified members
  • 10+ active networks
  • 50+ active groups
  • 200+ discussions created

Engagement Quality

  • 70% weekly active users
  • 5+ messages per user per week
  • 80% discussion completion rate
  • 4.5+ app store rating

Long-term Success Indicators

  • Network Effects: Cross-network discussion participation > 30%
  • Quality Control: Peer approval acceptance rate > 85%
  • Business Impact: Member-reported business connections and deals
  • Retention: 90-day retention rate > 60%
  • Organic Growth: 70% new members from peer referrals

Meaningful Connections per User per Month: Track the number of substantial professional or personal connections made through the platform, measured by mutual endorsement or collaboration initiation.
