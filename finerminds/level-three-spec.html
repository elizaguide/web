1. Level Three Overview

🎯 Core Philosophy

Level Three discussions are hyper-focused topic conversations that eliminate the noise of broader feeds. Think Reddit threads meets private Slack channels - anyone can create, but quality is maintained through invite-only access and admin controls.

Key Characteristics

  • NO Activity Feed: Discussions are pure chat - no posts, no likes, just conversation
  • Creator = Admin: Discussion creators automatically become admins with full control
  • Invite-Only: Controlled membership with configurable invite limits
  • Topic-Focused: Single-purpose conversations that stay on track
  • Resource Integration: Share relevant links and documents within context
Design Decision: Level Three eliminates activity feeds to solve cognitive overload. Users get content organization without feed overwhelm - they can have unlimited depth of discussion without complexity.

Initial Invitations

After creation, the system immediately prompts for initial invites:

  • Smart Suggestions: AI suggests relevant group members based on topic
  • Search & Filter: Find members by name, expertise, or previous interactions
  • Bulk Invite: Select multiple members with one-click invitation
  • Personal Message: Optional invitation message explaining the purpose
4

Discussion Activation

Once created and members invited, the discussion becomes active:

  • GetStream Channel: Automatic chat channel creation
  • Welcome Message: System message explaining purpose and admin
  • Notification Blast: All invited members get real-time notifications
  • Discovery: Discussion appears in group's discussion list (if not private)

3. Admin Controls & Management

Admin Privileges

Member Management

  • Add/remove members at any time
  • View member list with join dates
  • Transfer admin rights to other members
  • Set member roles (admin, moderator, member)

Discussion Settings

  • Edit title and description
  • Adjust invite limits up or down
  • Toggle privacy settings
  • Enable/disable member invitations

Moderation Tools

  • Delete inappropriate messages
  • Mute disruptive members temporarily
  • Pin important messages to top
  • Set discussion guidelines and rules

Discussion Lifecycle

  • Archive completed discussions
  • Mark discussions as "concluded"
  • Export conversation history
  • Permanently delete if necessary
Spam Prevention: To prevent abuse, users are limited to creating 5 new discussions per day. This can be adjusted based on usage patterns and community needs.

  • Screen Reader Support: Full ARIA labels and semantic markup
  • Keyboard Navigation: All features accessible via keyboard shortcuts
  • High Contrast Mode: Support for users with visual impairments
  • Text Size Scaling: Respect user's system text size preferences
