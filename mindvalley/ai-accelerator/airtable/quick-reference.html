🚨 Before You Start - Essential Setup

Required Steps (Do These First!)

  • Airtable Account: Sign up at airtable.com (free plan OK)
  • Enable AI Features: Go to workspace settings → Enable AI
  • Copy Training Template: Use the link from class (with "/copy" at end)
  • Select Demo View: Navigate to Posts table → Demo view

💰 Cost-Saving Settings

  • Model Choice: Select "Claude 4.5 Haiku" (low cost option)
  • Auto-run: Keep OFF initially to control credit usage
  • Internet Search: Toggle OFF unless external data needed

⚡ Quick Build Checklist

Creating AI Field Agent

  • Click the "+" button in table view
  • Select "Build a field agent"
  • Choose response type (Long text, Single select, etc.)
  • Configure AI model (Claude 4.5 Haiku recommended)
  • Write prompt with field references
  • Must use "Insert Field" button for dynamic content
  • Test on one record before mass generation

Essential Field Reference Format

Static prompt text + [Insert Field Button] + more context Example: "Create a LinkedIn post based on: [Blog Post] Optimized for audience: [Target Audience]"

🛠️ Field Agent Types & Use Cases

📝 Long Text Responses

Best for: Content creation, summaries, detailed analysis
Examples:
• Blog post → LinkedIn post conversion
• PDF summarization
• Email response drafting
• Product descriptions

🏷️ Single Select Responses

Best for: Categorization, classification, status updates
Examples:
• Content category assignment
• Sentiment analysis (Positive/Negative/Neutral)
• Priority levels (High/Medium/Low)
• Approval status (Approved/Rejected/Pending)

🔢 Number Responses

Best for: Scoring, ratings, calculations
Examples:
• Content quality scores (1-10)
• Risk assessments
• Performance metrics
• Time estimates

🔧 Common Issues & Solutions

"Can't Create Field" Error

Problem: Field agent won't save

Solution: Must include at least one field reference using "Insert Field" button

High Credit Usage

Problem: Burning through AI credits too fast

Solutions:

  • Switch to Claude 4.5 Haiku (lower cost)
  • Turn off auto-run
  • Test on fewer records initially
  • Disable internet search if not needed

Poor AI Responses

Problem: Generic or irrelevant outputs

Solutions:

  • Add more context fields to prompt
  • Be more specific in instructions
  • Include example outputs in prompt
  • Reference multiple relevant fields

Missing Context

Problem: AI can't find referenced information

Solutions:

  • Verify field names match exactly
  • Check that referenced fields have data
  • Ensure field types are compatible
  • Test with simple single-field reference first

🔗 Database Relationships Quick Guide

Linking Records

  • Link Field: Connects records between different tables
  • Two-way relationship: Changes appear in both linked tables
  • Example: Applicant → Position, Position → Multiple Applicants

When to Use Relations

  • Connect related data across tables
  • Avoid data duplication
  • Create complex multi-table workflows
  • Enable cross-referencing information

⚙️ Advanced Settings Explained

Internet Search

ON: AI can search web for additional context

OFF: AI only uses database information

Cost: Adds to per-generation credit usage

Google Drive/OneDrive Integration

  • Connect documents as additional context
  • Reference brand guidelines, templates, etc.
  • Requires initial authentication setup

Auto-run Options

  • Manual: Generate only when you click
  • Auto: Generates when new records added
  • Conditional: Set rules for when to run

🎯 Testing Strategy

1Phase 1: Single Record Test

  • Create agent with simple prompt
  • Test on one record with good data
  • Verify output quality and format

2Phase 2: Batch Test

  • Run on 3-5 similar records
  • Check consistency across outputs
  • Identify patterns in successes/failures

3Phase 3: Production Deploy

  • Refine prompt based on test results
  • Enable auto-run if desired
  • Monitor credit usage and output quality
