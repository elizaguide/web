⚡ Quick Start Guide

1. Include the Library

<link rel="stylesheet" href="mindvalley-core.css">
<link rel="stylesheet" href="mindvalley-utilities.css">
<script src="mindvalley-components.js"></script>

2. Generate Components

// In JavaScript
document.getElementById('hero').innerHTML = MV.hero({
  title: "Your Title",
  subtitle: "Your subtitle"
});

// Or use data attributes
<div data-mv-component="hero" data-mv-config='{"title":"Your Title"}'></div>

🚀 Complete Page Generator

Generate entire landing pages with one function call:

// Generate complete landing page
const page = MV.landingPage({
  hero: {title: "Transform Your Life", cta: "Start Now"},
  features: {title: "Why Choose Us", features: [...]},
  testimonial: {quote: "Amazing results!", author: "John Doe"},
  cta: {title: "Ready to Begin?", cta: "Get Started"}
});

// Write to file or inject into page
document.body.innerHTML = page;
