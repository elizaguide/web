## 🧠 CONVERSION PSYCHOLOGY FRAMEWORK

### Schwartz Stages (Awareness Progression)
1. **Unaware:** "I don't know this event exists"
   - Solution: Display ads, social media, partnerships
   
2. **Problem-Aware:** "My workweek is overwhelming"
   - Solution: Hero headline + problem agitation section
   
3. **Solution-Aware:** "Summits exist to teach this"
   - Solution: Event description + 3-day agenda
   
4. **Product-Aware:** "This specific summit has what I need"
   - Solution: Speaker credentials + social proof + testimonials
   
5. **Most-Aware:** "Should I register NOW?"
   - Solution: Urgency section + FAQ + easy registration

### Cialdini Principles Applied
- **Scarcity:** "While spots last", live event only, 3 days only
- **Social Proof:** 150K+ registered, 4 world-class speakers, 3 testimonials
- **Reciprocity:** Free value (entire 3-day event)
- **Authority:** Vishen's $100M+ track record, speaker credentials
- **Commitment:** Simple registration form = low friction commitment
- **Liking:** Relatable language, authentic testimonials, conversational tone

### Hormozi Value Equation
**Value = (Dream Outcome + Likelihood of Achievement) / (Time + Effort)**

**Applied to Landing Page:**
- **Dream Outcome:** 4-day work week + AI mastery + business scaling
- **Likelihood of Achievement:** 5-step method, 3-day intensive, live guidance
- **Time Required:** 3 days (low compared to outcome)
- **Effort Required:** Zero technical background needed
- **Result:** High value perception = High conversion

## 📞 SUPPORT & TROUBLESHOOTING

### Common Issues

**Form not submitting?**
- Check browser console for JavaScript errors
- Verify form element IDs match JavaScript selectors
- Test email backend is receiving POST requests

**Sticky CTA not showing?**
- Verify hero section height is at least viewport height
- Check scroll event listener is working (open DevTools Console)
- Test on different devices (may behave differently)

**Mobile layout broken?**
- Check viewport meta tag (should be: `<meta name="viewport" content="width=device-width, initial-scale=1.0">`)
- Test at 375px width (common mobile breakpoint)
- Verify CSS grid responsive breakpoints

**Countdown timer wrong?**
- Update the deadline date in JavaScript (line ~515)
- Verify your server timezone matches expected timezone
- Test in different timezones
